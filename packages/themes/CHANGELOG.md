# @atlasauth/themes changelog

## 0.1.0

First published release.

### Added
- Prebuilt `Appearance` presets for Atlas hosted pages and `@atlasauth/react` components: `base`, `dark`, `midnight`, `neobrutalism`, `shadcn`.
- `themes` object containing all presets.
- `experimental_createTheme()` for building a custom theme.
- Re-exports the `Appearance`, `DesignTokens` and `ElementKey` types.
